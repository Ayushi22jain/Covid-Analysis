## Covid-19 Data Analysis
This project provides an exploratory data analysis (EDA) of Covid-19 datasets, specifically focusing on regional data from Italy. The goal of this project is to apply statistical methods and advanced visualization techniques to understand the spread and impact of the virus.

# 📊 Project Overview
The analysis involves cleaning raw pandemic data and performing a deep dive into the numbers to uncover trends. By calculating key statistical metrics and creating multi-dimensional plots, this project offers a clear view of the data's distribution and correlations.

Key Analysis Features
Statistical Profiling: Calculated core metrics including Mean, Standard Deviation, and Averages to establish a baseline for the dataset.

Data Visualization: Utilized Seaborn and Matplotlib to create insightful graphics.

Relationship Mapping: Leveraged sns.relplot and sns.pairplot to identify correlations between different variables like confirmed cases, recoveries, and mortality rates.

# 🛠️ Tech Stack
Language: Python

Libraries: * Pandas (Data Processing)

NumPy (Numerical Operations)

Seaborn (Statistical Data Visualization)

Matplotlib (Plotting and Graphing)

Environment: Jupyter Notebook
